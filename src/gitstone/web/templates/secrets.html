Secrets scan

Scans every blob reachable in this dump -- not just the files checked out at one ref -- for common secret patterns (AWS keys, private key blocks, tokens, generic key = "..." assignments, .env lines). This is what finds a credential that was committed once and deleted in a later commit, which is the usual reason to recover a .git directory in the first place. It can't say which commit or path a hit came from without walking the whole history again, so it links to the raw blob instead.
